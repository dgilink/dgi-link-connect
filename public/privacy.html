개인정보처리방침

개정안 작성일: 2026년 9월 30일 · 최종 검토일: 2026년 10월 2일 · 시행일: 공개 배포 시 별도 고지

1. 적용범위

이 방침은 디지아이링크(DGI Link, 이하 “회사”)가 운영하는 Corporate Website dgilink.com의 방문과 이메일 문의에 적용됩니다. CardScan AI, kFarmAI 등 개별 제품·서비스의 계정, 결제, 이용자 데이터에는 해당 서비스의 별도 개인정보처리방침이 적용될 수 있습니다.

2. 개인정보 처리목적

회사는 이메일로 접수된 제휴 문의, B2B 문의, 서비스 문의 및 일반 문의를 처리하고, 문의에 회신하거나 필요한 후속 커뮤니케이션을 하기 위해 개인정보를 처리합니다. 이 웹사이트에는 회원가입, 로그인, 문의 입력폼 또는 이용자 데이터베이스가 없습니다.

일반 문의 정보를 별도 동의 없이 광고·마케팅 목적의 명단으로 사용하지 않습니다.

3. 실제 처리항목

웹사이트 직접 방문 회사가 웹페이지 입력폼이나 분석도구로 직접 수집하는 항목은 없습니다. 호스팅 제공자 GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록합니다.
이메일 문의 이메일 주소, 문의 내용 및 문의자가 직접 제공한 이름, 소속·회사명(제공한 경우), 그 밖에 문의 과정에서 직접 제공한 정보
언어 설정 언어 선택 시 브라우저 localStorage에 dgi-lang 값(ko/en/ja)만 저장됩니다. 이 값은 회사 서버로 전송하거나 개인 식별에 이용하지 않습니다.

회사는 이 Corporate Website에서 앱 계정 이메일, 명함 이미지, 기기식별자, 결제수단 정보, 개별 앱 이용 데이터를 직접 수집하지 않습니다.

4. 보유·이용기간

일반 문의 개인정보 및 이메일은 문의 처리 완료일부터 1년간 보유합니다. 이 웹페이지 자체는 문의메일을 수신하거나 보관하지 않으며, 문의메일은 업무메일 운영환경에서 처리합니다.

법령상 보존의무, 실제 계약·거래 또는 분쟁 대응 등 별도의 정당한 보존근거가 있는 경우에는 일반 문의 보유기간과 구분하여 해당 근거에 따른 기간을 적용할 수 있습니다. 이 경우 보존 근거, 대상 정보와 적용 기간을 구분하여 관리합니다.

언어 설정은 다시 선택하면 변경되며, 방문자 또는 브라우저가 저장 데이터를 삭제하면 제거됩니다. 웹페이지는 언어 설정에 별도의 만료기간을 설정하지 않습니다. 호스팅 제공자의 접속정보 보관에는 해당 제공자의 정책이 적용됩니다.

5. 파기절차 및 방법

보유기간 만료 여부와 별도 보존근거를 확인한 뒤, 보존할 근거가 없는 해당 문의 이메일과 개인정보를 삭제하는 것을 운영원칙으로 합니다. 별도의 정당한 보존근거가 있는 정보는 해당 근거에 따른 기간 동안 구분하여 관리하고, 그 기간이 종료되면 삭제 대상으로 확인합니다.

6. 제3자 제공

회사는 일반 문의 개인정보를 독립된 제3자에게 임의로 제공하지 않습니다. 법령상 요구가 있거나 문의자가 별도로 동의한 경우 등에는 관련 법령 또는 동의 범위에 따릅니다. 업무메일 서비스 이용과 호스팅 접속정보 처리는 아래 제7항과 제8항에서 구분하여 안내합니다.

7. 처리위탁

이 웹사이트는 GitHub Pages에서 정적 파일로 제공되며, 별도의 회원정보 저장이나 문의폼 처리 시스템을 운영하지 않습니다. 호스팅 제공자의 접속정보 처리는 GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침에서 확인할 수 있습니다.

회사는 contact@dgilink.com 업무메일의 송수신에 Google Workspace를 사용합니다. 업무메일 이용에 따른 처리위탁에 관한 사항은 실제 계약과 데이터 처리 약정(DPA)에 따른 관계 및 업무 범위를 확인하여 안내합니다.

8. 국외이전

이 웹페이지에는 개인정보를 수집하여 별도 API로 국외 전송하는 기능이 없습니다. 다만 GitHub는 접속정보를 미국 등 여러 국가에서 처리할 수 있다고 안내하고 있으므로, 호스팅 과정의 정보가 국내에서만 처리된다는 의미는 아닙니다. 자세한 내용은 GitHub 국외이전 안내를 참고하세요.

Google Workspace 업무메일의 처리 위치와 국외이전 관련 사항은 실제 계약 및 데이터 처리 약정에 따라 확인해야 합니다. 업무메일이 대한민국에서만 저장·처리된다고 보장하지 않습니다. 국외이전에 해당하는 처리가 있는 경우 실제 이전 항목, 국가, 일시와 방법, 이전받는 자, 목적 및 보유기간을 확인하여 관계 법령에 따라 안내합니다. 위의 GitHub 호스팅 안내는 Google Workspace 업무메일의 처리 국가나 계약주체를 의미하지 않습니다.

9. 정보주체의 권리와 행사방법

정보주체는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지 또는 동의 철회를 요청할 수 있습니다. 본인 확인이 필요한 경우 최소한의 확인 절차를 요청할 수 있으며, 법정대리인은 관계 법령에 따라 권리를 행사할 수 있습니다.

권리 행사 및 문의: contact@dgilink.com

10. 자동수집 기술

회사는 이 Corporate Website에서 광고 쿠키, 행동 추적 분석도구, 광고 픽셀, 맞춤형 광고 또는 프로파일링을 사용하지 않습니다. 언어 선택을 기억하기 위한 localStorage만 사용하며, 브라우저 설정 또는 저장 데이터 삭제 기능으로 언제든 제거할 수 있습니다.

11. 안전성 확보조치

웹사이트에는 개인정보 입력폼이나 이용자 데이터베이스를 두지 않고, 브라우저에는 언어 선택값만 저장하도록 처리 범위를 최소화했습니다. 이메일 문의 정보에 대해서는 필요한 담당자만 접근하도록 하고 안전한 계정 관리와 전송구간 보호 등 처리 환경에 적합한 조치를 마련하는 것을 보호 원칙으로 합니다.
